# Incident Intelligence Platform

Platform helping engineers analyse incidents,
logs and technical issues using AI-assisted
root cause analysis.

## Goals

- Incident management
- Log analysis
- Knowledge base
- Root cause suggestions
- AI assistant
- Audit trail

## Planned Tech Stack

Backend:
- Java
- Spring Boot
- PostgreSQL

Frontend:
- TypeScript
- React

AI:
- Python
- FastAPI

Infrastructure:
- Docker
- GitHub Actions
- Azure
